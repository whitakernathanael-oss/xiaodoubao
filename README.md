# 豆包皮肤版（Doubao AutoSkin）

一个面向豆包 Windows 客户端的本地开源主题编辑器。它通过豆包的本机 Chrome DevTools Protocol 调试端口注入样式，不修改豆包安装文件，也不读取或上传聊天内容。

> 本项目与字节跳动、豆包官方无隶属或授权关系。豆包更新可能改变页面结构，届时需要更新本地适配器。

## 系统要求

- Windows 10/11 64 位
- 64 位双核 CPU；四线程以上更合适
- 8 GB 内存最低，16 GB 推荐
- 已安装豆包 Windows 客户端

当前测试机稳定态私有内存合计约 140 MB；建议为大图解码和 ZIP 导入预留约 300 MB。

## 功能范围

- 三个只读内置主题：清透晨光、午夜墨蓝、云端玻璃
- PNG、JPG、JPEG、WebP 静态壁纸
- 完全本地的 64×64 自动取色
- 壁纸、侧栏、聊天区、输入框、按钮/卡片和设置面板控制
- 简化聊天/设置预览、30 步撤销和区域重置
- 普通 ZIP 主题包导入导出
- 可替换的单一豆包页面适配器
- 一键应用与恢复官方外观

不包含 GIF/视频、云同步、账号、付费、主题商城、遥测、托盘守护程序或自动适配器更新。私人定制主题与免费主题使用完全相同的开放格式。

## 从源码运行

```powershell
git clone <仓库地址> doubao_autoskin
cd doubao_autoskin
npm install
npm run start
```

运行测试和类型检查：

```powershell
npm test
npm run typecheck
```

生成 Windows x64 安装包和 ZIP：

```powershell
npm run make
```

产物位于 `out\make\`。

## 首次使用

1. 打开“豆包皮肤版”。
2. 点击右上角“启动 / 连接”。如果豆包已经运行但未开启调试端口，请按弹窗提示从系统托盘正常退出豆包，再点“已退出豆包，继续”；工具不会强制结束进程。
3. 选择内置主题，或点击主题区的 `＋` 复制为可编辑主题。
4. 选择静态壁纸并调整区域样式。
5. 点击“保存主题”，再点击“应用到豆包”。
6. 需要撤销注入时点击“恢复官方外观”。

工具只连接 `127.0.0.1` / `::1` 回环地址。关闭编辑器后，当前页面上的皮肤通常保留到豆包页面刷新；重新打开工具并点击应用即可继续监听页面重载。

## 主题与 ZIP

用户主题保存在 `%LOCALAPPDATA%\DoubaoSkin\themes\`。导入和导出使用普通 `.zip`；同名主题自动添加 `-2`、`-3` 后缀。

开发者和 Agent 请阅读：

- [主题格式](docs/theme-format.md)
- [Agent 主题制作指南](docs/agent-theme-guide.md)
- [豆包适配器](docs/doubao-adapter.md)

主题包不能包含 JavaScript、HTML、字体、可执行文件、远程资源或嵌套压缩包。可选 `extra.css` 必须锚定主题作用域。

## 已知限制

- 豆包升级后，适配器选择器可能失效；缺少必需区域时工具会拒绝注入，豆包保持官方外观。
- 内置适配器已在豆包 2.22.7 实测；首次启用调试端口需要用户从托盘正常退出一次。
- MVP 只支持一张静态壁纸，不支持动画和视频。
- 预览是本地简化结构，不是嵌入的真实豆包页面。
- 工具关闭后没有后台守护进程，不保证页面刷新后的自动重注入。

## 隐私与安全

- 不联网下载主题、适配器或资源。
- 不上传壁纸、配置和日志。
- 不读取输入框值、账号标识或聊天正文。
- 日志仅保存时间、阶段、错误类型、目标地址和选择器匹配数量，最大 2 MB。
- 渲染进程启用沙箱、上下文隔离和关闭 Node.js 集成。
- 适配器只允许明确列出的豆包页面，后台、登录和辅助页面被排除。

## 卸载

1. 在工具中点击“恢复官方外观”。
2. 卸载应用或删除解压目录。
3. 如需同时删除自定义主题和设置，删除 `%LOCALAPPDATA%\DoubaoSkin\`。

删除本地数据不可恢复，请先导出需要保留的主题 ZIP。
