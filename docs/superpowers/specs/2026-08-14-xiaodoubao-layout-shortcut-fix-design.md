# 小豆包顶栏、消息气泡与快捷方式修复设计

## 目标

1. 删除编辑器左上角整块品牌标识，包括图标、主标题和副标题。
2. 修复豆包聊天中用户消息的双层边框与过窄问题。
3. 将 Windows 用户可见快捷方式名称稳定迁移为“小豆包”。

## 界面设计

编辑器顶栏不再渲染 `.wordmark`。状态、更多菜单和“启动 / 连接”仍保留在右侧；顶栏继续保持单行、紧凑、可缩放。

用户消息只允许一层视觉气泡。当前适配器把 `dbs-message-user` 标到内部文字节点，外层仍保留豆包原生发送消息容器，因此出现嵌套边框。修复时把用户消息标记改到 `[data-testid="send_message"]` 外层容器；主题背景、边框、圆角与阴影只画在这个外层。文字节点不再单独画框。

用户气泡使用：

- `width: fit-content`
- `min-width: min(360px, 72%)`
- `max-width: min(72%, 760px)`
- 小屏幕允许缩小，不产生横向溢出
- 长文字使用 `overflow-wrap: anywhere`

豆包回复继续保持透明、无边框、无圆角、无阴影。

## 快捷方式迁移

当前 0.1.20 快捷方式已指向 `小豆包.exe` 和新图标，但 Squirrel 仍使用内部名称生成 `doubao-autoskin.lnk`。内部包名和更新标识不能修改，否则可能破坏既有安装。

因此安装、升级完成后增加 best-effort 的快捷方式重命名：

- 开始菜单中的 `doubao-autoskin.lnk` 改为 `小豆包.lnk`
- 桌面中如存在 `doubao-autoskin.lnk`，也改为 `小豆包.lnk`
- 兼容旧 `豆包皮肤版.lnk`
- 只改快捷方式文件名，不改内部 `doubao-autoskin` / `doubao_autoskin`
- 失败不阻止安装或启动

## 测试与发布

- DOM/注入测试必须覆盖外层用户消息标记，确认内部文字节点不再获得用户气泡类。
- CSS 测试覆盖 360px 最小宽度、72%/760px 最大宽度以及助手无框。
- Renderer 测试确认品牌块不再存在。
- Windows 包测试覆盖快捷方式重命名逻辑和内部标识不变。
- 版本升级为 `0.1.21`，重新生成 `小豆包-Setup.exe` 与便携版 `小豆包.exe`。

## 不在范围内

- 不修改主题 ZIP 格式、用户主题、适配器的其他区域、皮肤持久化或豆包启动流程。
- 不修改官方豆包客户端的产品名称。
- 不新增依赖。
