# 小豆包对话样式与品牌更新设计

## 目标

本次更新只处理三件事：优化注入豆包后的消息显示、替换小豆包图标、把所有用户可见的桌面程序名称统一为“小豆包”。不改变主题格式、壁纸取色、皮肤持久化或豆包启动接管逻辑。

术语约定：本文中的“小豆包”和“豆包皮肤”都指本项目；“豆包”指官方客户端。

## 对话样式

现有适配器已经用稳定的 `data-testid` 分别识别用户消息和豆包回复，并由注入器标记为 `.dbs-message-user` 与 `.dbs-message-assistant`。本次不扩大或替换选择器。

### 用户消息

- 保留主题生成的气泡颜色、边框、圆角与轻量阴影。
- 气泡使用 `width: fit-content`。
- 最小宽度使用响应式范围，目标为 `clamp(280px, 28vw, 480px)`，避免短消息形成过窄小块。
- 最大宽度不超过聊天区域约 72%，同时设置合理像素上限，长消息自动换行。
- 小窗口下允许宽度收缩，不产生横向滚动。

### 豆包回复

- 恢复接近豆包官方设计的无框正文。
- 清除回复正文节点的背景、边框、圆角、阴影与额外容器内边距。
- 不强制修改文字颜色，继续使用豆包自身颜色与现有对比度保护。
- 不影响回复中的图片、引用、表格和代码块；代码块仍保留其专用表面样式。

### 本地预览

本地预览与真实注入保持一致：用户消息显示加宽气泡，豆包回复显示无框正文，避免“预览一种效果、应用后另一种效果”。

## 图标

使用用户提供的：

`D:\admin\新建文件夹\g3u7e-80e24\p3r68-cdx67\g3u7e-80e24-001.ico`

覆盖项目的 `assets/icon.ico`。该文件包含 16、24、32、48、256 像素的 32 位图标，可用于 Windows 多种显示尺寸。

覆盖范围：

- Electron 窗口与任务栏图标；
- 打包后的 EXE 图标；
- 安装程序图标；
- 桌面与开始菜单快捷方式图标。

窗口创建时显式指定 `assets/icon.ico`，避免开发运行或特殊 Windows 场景回退为 Electron 默认图标。

## 名称与升级迁移

所有用户可见名称统一为“小豆包”：

- `productName`；
- 主程序 `小豆包.exe`；
- 安装程序 `小豆包-Setup.exe`；
- 窗口标题、错误提示标题、退出提示；
- 编辑器顶部品牌名称；
- 桌面与开始菜单快捷方式名称。

内部包名和更新标识继续使用 `doubao-autoskin` / `doubao_autoskin`，避免破坏用户数据目录和 Squirrel 更新链路。

安装或升级新版时：

1. 尝试移除旧的“豆包皮肤版”快捷方式；
2. 创建新的“小豆包”快捷方式；
3. 卸载时同时清理新旧两个名称的快捷方式；
4. 所有快捷方式迁移操作为尽力执行，单个旧快捷方式不存在时不能阻止安装。

## 错误处理

- 图标资源缺失必须在打包测试阶段失败，不能静默生成默认图标。
- 快捷方式迁移保持当前 Squirrel 的容错方式，失败交给安装器报告，不影响普通运行。
- 消息节点暂时不存在时继续由现有 MutationObserver 在 DOM 更新后重新标记。

## 测试与验收

### 自动测试

- 注入 CSS：用户消息存在响应式最小/最大宽度；豆包回复没有气泡背景、边框和阴影。
- 本地预览：只给用户消息绘制气泡，豆包回复无框。
- 图标：ICO 文件存在、签名有效，BrowserWindow 显式使用该资源。
- 品牌：用户可见名称全部为“小豆包”，内部包名保持不变。
- Squirrel：安装/更新创建“小豆包”快捷方式并清理旧名称；卸载清理新旧名称。
- Windows 打包：生成 `小豆包-Setup.exe` 与 `小豆包.exe`。

### 手工验收

- 短用户消息不再显得过窄，长消息不超出聊天区域。
- 豆包长回复、图片与代码块正常显示，正文没有大面积气泡框。
- 窗口、任务栏、安装包、桌面快捷方式均显示新图标。
- 全新安装桌面名称为“小豆包”；覆盖升级后不再保留“豆包皮肤版”旧快捷方式。

## 非目标

- 不重做豆包消息排版和字体。
- 不新增消息宽度调节面板。
- 不修改主题 ZIP 格式或适配器选择器。
- 不迁移内部应用 ID、用户数据目录或更新包标识。
