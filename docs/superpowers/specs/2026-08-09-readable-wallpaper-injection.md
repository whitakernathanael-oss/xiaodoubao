# 真实豆包壁纸与可读性修复

## 目标

让上传图片和区域颜色在真实豆包聊天页可见，同时不改变豆包原有文字颜色，并在系统深浅模式下保持可读。

## 已确认约束

- 豆包文字深浅跟随 Windows；皮肤工具不得覆盖 `color`、`fill`、`caret-color`。
- 壁纸只挂载到已适配的聊天区，不再放在页面最底层等待透明页面露出。
- 注入时读取聊天文字的实际计算颜色，明亮文字使用黑色安全遮罩，深色文字使用白色安全遮罩。
- 安全遮罩与用户选择的装饰遮罩叠加；安全遮罩的最低不透明度保证图片再亮或再暗也不会直接压住文字。
- 侧栏、消息、输入框、按钮和设置面板使用与当前文字模式相容的安全底色，保留用户选色的色相，不改变字体。
- 本地预览按当前系统深浅模式模拟同一保护策略。
- 编辑器移除不能真实生效的“文字色”控件；已有主题字段为兼容保留。

## 不做

- 不修改 Windows 或豆包主题。
- 不读取、保存或上传用户聊天内容。
- 不新增动画壁纸、主题商店或付费能力。

## 验收

1. 深色 Windows 下，白字始终落在深色保护层上；亮色壁纸仍可辨认。
2. 浅色 Windows 下，深字始终落在浅色保护层上；暗色壁纸仍可辨认。
3. 上传壁纸后，真实聊天区可见图片，而不是只在本地预览可见。
4. 应用和恢复后，无遗留挂载层、样式、类名或 CSS 变量。
