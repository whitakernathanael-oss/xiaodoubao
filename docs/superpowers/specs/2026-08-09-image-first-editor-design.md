# 图片优先主题编辑器设计

## 目标

把普通用户的操作收敛为“上传一张图片、选择三个风格之一、应用到豆包”。颜色、卡片、按钮和文字不再逐项手调。

## 用户界面

左侧只保留三个内置主题：清透晨光、云端玻璃、午夜墨蓝。主题列表仍支持导入、导出和删除自定义主题。

右侧只显示“壁纸”页：选择静态壁纸、铺满或完整显示、水平位置、垂直位置、缩放、模糊、亮度。移除所有颜色选择器、区域标签页、撤销和“重置当前区域”。

主题名称、保存主题、应用到豆包和恢复官方外观保留。

## 主题行为

上传图片时继续在本地提取调色板，但不显示给普通用户。注入器以该调色板为装饰色来源，结合已选主题的固定布局风格。

豆包的系统文字颜色始终不被改写。实际网页若为浅色文字，注入黑色安全层；若为深色文字，注入白色安全层。三个风格仅改变壁纸构图、卡片质感和强调色；每种风格都自动适配两种系统文字模式。

## 高级 DIY

主题 JSON 的现有区域颜色、透明度、圆角和阴影字段继续支持导入和导出，不删除架构或旧主题。普通编辑器不显示这些字段。Agent、开发者和私人定制可继续修改主题包。

## 主题卡片

主题卡片的色块必须来自该主题自身的 `palette.surface` 和 `palette.accent`，不得依据它在列表中的第几个位置设置颜色。这样“云端玻璃”始终显示浅蓝色块，“午夜墨蓝”始终显示深蓝色块，导入主题也能显示自己的预览色。

## 验收

1. 普通用户界面不存在颜色输入、区域标签、撤销或区域重置。
2. 上传图片后，预览和实际注入仍使用提取的主题调色板。
3. 导入旧主题、导出主题、应用和恢复流程不变。
4. 深色与浅色系统下，预览和真实注入都不覆写豆包文字颜色。
