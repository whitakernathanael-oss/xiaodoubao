# 小豆包用户消息气泡对齐官方界面设计

## 目标

修复主题注入后用户消息出现左侧大矩形的问题。注入后的用户消息必须保留豆包官方的右对齐、内容自适应宽度、内边距和圆角，只改变主题颜色。

## 根因

当前适配器把 `.dbs-message-user` 标记在 `[data-testid="send_message"]` 外层。该外层属于消息行布局容器，但注入 CSS 同时给它设置了背景、边框、阴影、`display:block`、`width:fit-content` 和 `min-width:360px`。这覆盖了豆包原生的右对齐布局，并把整行容器画成了气泡。

## 设计

采用“外层定位、内层上色”：

- 继续把 `.dbs-message-user` 标记在 `[data-testid="send_message"]`，用于稳定识别用户消息。
- `.dbs-message-user` 外层不设置背景、边框、阴影、宽度、最小宽度、最大宽度、display、margin、padding 或对齐属性。
- 主题颜色只应用到 `.dbs-message-user [data-testid="message_text_content"]`。
- 内层只覆盖颜色相关属性：背景色、文字色、边框颜色；不覆盖宽度、内边距、圆角和阴影，优先继承豆包官方气泡几何尺寸。
- 豆包回复继续保持无框，不新增用户气泡之外的布局覆盖。

## 本地预览

预览结构改成“消息行 + 内部气泡”两层：

- 消息行负责右对齐。
- 内部气泡按文字内容自适应。
- 删除预览中的 360px 强制最小宽度。
- 预览仅模拟主题颜色，不自创另一套尺寸规则。

## 测试

必须先增加失败测试，再修改生产代码：

- 外层用户消息规则不得包含 display、width、min/max-width、margin、padding、background、border 或 shadow。
- 内层文字节点得到主题颜色，但不出现强制几何属性。
- 同一条消息只有内部节点是可见气泡。
- 预览用户消息右对齐并按内容自适应，不含 360px 最小宽度。
- 豆包回复继续无框。
- 全量测试、类型检查和 Windows 打包通过。

## 范围

只修改注入 CSS、预览结构/样式及对应测试。不修改适配器选择器、主题数据、持久化、守护启动或快捷方式逻辑。
