# 豆包皮肤版简约工作台设计

## 目标

整体优化豆包皮肤版界面，修复顶部自动运行设置和长说明挤成一团的问题。保留现有 MVP 功能与业务行为，不增加新功能，不引入新依赖。

## 视觉方向

- 黑、白、灰为主，不使用紫色。
- 不使用品牌渐变、彩色光晕或装饰性动画。
- 绿色只用于“服务正常运行”状态。
- 主题颜色只出现在主题缩略图和豆包预览中。
- 控件采用简洁桌面工具风格：清楚边框、小圆角、稳定间距、明确主次。

## 页面结构

### 顶部栏

只放以下内容：

- 豆包皮肤版标识；
- 当前主题名称；
- 简短运行状态；
- “打开豆包”按钮；
- 更多操作入口。

顶部不再放三个自动运行开关，也不再放长说明。

### 左侧皮肤库

- 显示主题名称、类型和缩略色块。
- 当前主题使用黑色细标记和轻边框表示。
- 保留导入、导出、删除功能。
- 删除放入更多菜单，避免与常用操作同级。

### 中间实时预览

- 作为页面最大区域。
- 保留“聊天 / 设置”预览切换。
- 保留壁纸、侧栏、气泡、输入框等真实主题预览。
- 预览提示使用可读的小号文字，不低于 11px。

### 右侧主题设置

分为两个页签：

1. 外观
   - 选择静态壁纸；
   - 填充方式；
   - 水平位置；
   - 垂直位置；
   - 缩放；
   - 模糊；
   - 亮度。

2. 自动运行
   - 自动保持皮肤；
   - 关闭豆包前询问；
   - 暂时停用皮肤；
   - 暂时停用说明。

“暂时停用皮肤”的说明正常换行显示在对应开关下方：停用后不再后台检测或开机启动；已保存主题不会删除；当前豆包皮肤不会立即移除。

### 操作区

- “保存主题”和“应用到豆包”固定在右侧底部。
- “应用到豆包”使用深灰主按钮。
- “恢复官方外观”降级为次要危险操作，与常用按钮分开。

## 响应式行为

- 默认桌面宽度保持左库、中预览、右设置三栏。
- 1100px 以下缩窄左右栏，优先保证中间预览。
- 900px 以下右侧设置变为覆盖式侧栏或可滚动区域，不压缩顶部状态。
- 所有长说明允许换行；按钮和状态文字不得挤成竖排。

## 代码范围

- `src/renderer/app.ts`：调整 DOM 结构和设置分组，保留现有 `data-action`、事件、队列与 IPC 行为。
- `src/renderer/styles.css`：重建界面布局和视觉样式，删除无用 `.panel-title > button` 规则。
- `tests/renderer.test.ts`：验证自动运行说明位于设置区而非顶部；三个开关行为保持不变。
- 如需视觉验收，可增加只读截图脚本或人工验收步骤；不引入 UI 框架依赖。

## 明确不做

- 不把项目迁移到 React、Tailwind 或 shadcn 运行时。
- 不新增在线主题市场、账号、付费、云同步。
- 不修改主题格式、取色算法、注入逻辑或后台守护逻辑。
- 不删除主题导入导出、预览、自动保持、询问和暂时停用功能。

## 验收标准

1. 默认窗口下顶部无拥挤、重叠或竖排文字。
2. 760px 最小窗口下顶部仍能读取状态和操作按钮。
3. 暂时停用说明只出现在“自动运行”设置区，正常换行。
4. 三个自动运行开关读写行为与当前版本一致。
5. 主题选择、壁纸上传、参数调整、保存、应用、恢复、导入导出全部可用。
6. 主题预览仍能正确显示壁纸和主题配色。
7. 全量测试、类型检查、UI 检测和 Windows 打包通过。
